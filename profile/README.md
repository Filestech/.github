# files tech

**Open source mobile apps — privacy first, Apache 2.0.**

Files Tech builds Android apps designed to run entirely on your phone — no cloud, no tracking, no permissions you didn't ask for.

→ Website: [files-tech.com](https://files-tech.com)
→ Contact: contact@files-tech.com
→ Distribution: F-Droid (reproducible builds)

---

## The apps

- **SMS Tech** — SMS/MMS replacement: encrypted vault, voice messages, local translation, panic code, biometrics.
- **Pass Tech** — Password manager 100% local: per-domain anti-phishing, decoy vault, panic mode, post-inactivity heir.
- **Notes Tech** — Encrypted Markdown notes: per-folder vaults, semantic search, on-device Gemma Q&A, Whisper dictation.
- **AI Tech** — Conversational AI 100% on-device: Gemma, Qwen, Phi, Llama via MediaPipe / LiteRT-LM.
- **PDF Tech** — Read, create, merge, sign, protect and OCR your PDFs — entirely on your phone.
- **Read Files Tech** — File explorer, universal reader, scanner, OCR, PDF signing, AES-256 vault, global search.
- **Health Tech** — Wellness practitioner journal: clients, animals, sessions, agenda, SQLCipher AES-256.

All apps: Apache 2.0 source code, no Internet permission unless strictly needed, on-device only.
